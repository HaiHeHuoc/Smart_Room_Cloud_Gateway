# Text bridge module

Private `xiaozhi_foundation` submodule for semantic-text bridging around the
managed Xiaozhi chat initialization path.

- **Owner:** `xiaozhi_foundation`
- **Visibility:** private source; provider callback payloads are copied/translated
  before crossing the project boundary.
- **Lifecycle:** no independent task or transport owner.
- **Promotion rule:** keep private unless the semantic-text adapter becomes a
  provider-neutral reusable service.
